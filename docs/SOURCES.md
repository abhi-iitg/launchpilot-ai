# Sources & Design References

This project was developed as original portfolio work using public product-management patterns for inspiration. It is not a fork or copy of any reference repository.

## Public references reviewed

1. **AI Product Playbook — sadasib**  
   https://github.com/sadasib/ai-product-playbook  
   Useful pattern: customer problem → AI PRD → evaluation → launch readiness → executive decision; five launch gates covering customer value, AI quality, trust/safety, operations and business readiness.

2. **AI Product Experiment Platform — nolanefe**  
   https://github.com/nolanefe/ai-product-experiment-platform  
   Useful pattern: evidence → personas → controlled experiment → deterministic analysis → decision memo → real-user validation.

3. **Product Discovery Skills — datapanda**  
   https://github.com/datapanda/product-discovery-skills  
   Useful pattern: evidence-grounded discovery, explicit uncertainty and inspectable product artifacts.

4. **Enterprise AI Product Management Toolkit — MautikPatel**  
   https://github.com/MautikPatel/Enterprise-AI-Product-Management-Toolkit  
   Useful pattern: connecting product requirements, governance, risk, testing, launch readiness and closure.
